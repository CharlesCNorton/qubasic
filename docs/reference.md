# QUBASIC reference

This file is generated by `tools/generate.py` from the command docstrings, the
statement and function catalog (`qubasic_core/parser.py`), the gate table, the
memory map, the command-line table and the API docstrings; `HELP <name>` prints
the same entries at the prompt.

Syntax uses `[optional]` and `a | b` for alternatives; lower-case words and `<names>`
stand for values you supply.
Commands are typed at the prompt (most also work as program lines); statements are
program lines, and most can be typed at the prompt as well.

## Commands

### Program editing

| Command | Syntax | Description |
|---|---|---|
| LIST | `LIST [SUBS \| VARS \| ARRAYS]` | Show the program, or its procedures, variables or arrays. |
| EDIT | `EDIT <line>` | Edit a specific line. |
| DELETE | `DELETE line \| start-end` | Remove program lines. |
| RENUM | `RENUM [start] [step]` | Renumber lines and every line-number reference (GOTO, GOSUB, ON ... GOTO/GOSUB lists, ON ERROR GOTO, RESUME, RETURN, RESTORE, and IF ... THEN/ELSE <line>); string literals and comments keep their text. |
| AUTO | `AUTO [start][, step]` | Auto-generate line numbers. |
| COPY | `COPY <start>-<end> TO <dest>` | Copy line range. |
| MOVE | `MOVE <start>-<end> TO <dest>` | Move line range. |
| FIND | `FIND "text"` | Search program lines. |
| REPLACE | `REPLACE "old" WITH "new"` | Find and replace in program. |
| UNDO | `UNDO` | Undo the last program edit, showing what changes. |
| NEW | `NEW` | Clear program, subroutines, registers, and variables. |
| BANK | `BANK <n>` | Switch to program slot n. |
| DIFF | `DIFF <slot>` | Diff current program against another bank slot. |
| CHECKSUM | `CHECKSUM` | Hash of program listing for verification. |
| EXPLAIN | `EXPLAIN` | Describe each program line in plain English. |

### Running and debugging

| Command | Syntax | Description |
|---|---|---|
| RUN | `RUN` | Execute the stored program: build and simulate its circuit, or run it live (shot by shot) when it reads measurement results, or on the LOCC or encoded engines in those modes, then show the histogram (and any picture the program drew on a graphics SCREEN). |
| STEP | `STEP` | Step through the program a line at a time, showing the state after each. |
| CONT | `CONT` | Continue execution after STOP, resuming from the next line. |
| TRON | `TRON` | Trace on, print each line number during execution. |
| TROFF | `TROFF` | Stop printing line numbers as the program runs. |
| BREAK | `BREAK <line> \| BREAK CLEAR \| BREAK LIST \| BREAK <start>-<end>` | Manage breakpoints. |
| WATCH | `WATCH [expr \| CLEAR]` | Add or remove a watch expression, list them, or clear them. |
| REWIND | `REWIND [N]` | Go back N steps in the statevector history. |
| FORWARD | `FORWARD [N]` | Go forward N steps in the statevector history. |
| HISTORY | `HISTORY` | Show statevector checkpoint list. |
| PROFILE | `PROFILE [ON\|OFF\|SHOW]` | Toggle profiling or show results. |
| STATS | `STATS [N\|SHOW\|CLEAR\|CSV <file>]` | Run the program N times and summarize the counts. |
| SEED | `SEED n \| OFF` | Fix the random seed so runs repeat, or release it. |

### Configuration

| Command | Syntax | Description |
|---|---|---|
| QUBITS | `QUBITS [n]` | Set or show the qubit count; the ceiling is per METHOD (statevector 32, stabilizer 4096, MPS and automatic 1024). |
| SHOTS | `SHOTS [n]` | Set or show the number of measurement shots. |
| METHOD | `METHOD [name \| CPU \| GPU]` | Set or show the simulation method or device (no argument probes what is available). |
| PRECISION | `PRECISION [SINGLE\|DOUBLE]` | Amplitude precision: SINGLE halves the memory of statevector, density-matrix and numpy-engine runs, which buys one more qubit at the statevector wall. |
| STATUS | `STATUS [JSON]` | Show every active mode (qubits, method, LOCC, noise, OPTION BASE, pending state injections, bank, ...) so behavior is readable rather than inferred. STATUS JSON emits the same data as JSON. |
| VERSION | `VERSION` | Print build ID, simulator versions, and feature flags. |
| COUPLING | `COUPLING linear\|ring\|heavyhex\|full\|OFF\|<edges>` | Constrain 2-qubit connectivity. |
| BASIS | `BASIS <gate list>\|OFF` | Restrict transpilation to a native gate set. |
| DEVICE | `DEVICE <topology> [n] [T1us] [T2us]` | Load a calibrated offline device model. |
| OPTIMIZE | `OPTIMIZE [level]` | Transpile the program and report the reduction. |
| RAM | `RAM` | Memory now available, what the current configuration costs, and the widest statevector that fits at each precision. |
| BENCH | `BENCH [n1 n2 ...]` | Time a statevector run (H, a CX chain and T on every qubit, 100 shots) at each qubit count with its memory; a count that does not fit in available memory is skipped. |

### Analysis

| Command | Syntax | Description |
|---|---|---|

## Statements

### Program flow

| Syntax | Description |
|---|---|
| `GOTO line \| label` | Jump to a line number or label. |
| `GOSUB line \| label` | Call a subroutine; RETURN comes back to the next statement. |
| `RETURN [line \| label]` | Return from GOSUB, optionally to another line. |
| `ON n GOTO \| GOSUB target1, target2, ...` | Jump or call by the value of n (1 picks the first target). |
| `IF cond THEN stmts [ELSE stmts]` | Single-line conditional; THEN or ELSE may name a line. |
| `IF cond THEN / ELSEIF cond THEN / ELSE / END IF` | Block conditional. |
| `FOR v = a TO b [STEP s] ... NEXT [v]` | Counted loop; zero-trip when the step cannot reach b. |
| `WHILE cond ... WEND` | Pre-test loop. |
| `DO [WHILE \| UNTIL cond] ... LOOP [WHILE \| UNTIL cond]` | Loop with the test at either end, or none. |
| `EXIT FOR \| WHILE \| DO \| SUB \| FUNCTION` | Leave the innermost loop or procedure of that kind. |
| `SELECT CASE expr / CASE v, a TO b, IS > v / CASE ELSE / END SELECT` | Multi-way branch on values, ranges and comparisons. |
| `END` | End the program. |
| `STOP` | Break into the debugger; CONT resumes. |
| `SYSTEM` | End the program. |
| `SLEEP [seconds]` | Pause. |
| `REM text \| ' text` | Comment. |
| `name:` | A line label, the target of GOTO, GOSUB, RESTORE, RESUME and ON ERROR. |

## Python API

`from qubasic_core import run, Session` runs programs without a terminal; the
`qubasic_core.api` docstring has worked examples.

| Name | Call | Description |
|---|---|---|
| run | `run(source, *, basic=None, **settings)` | Load `source`, RUN it and return the result: counts, num_qubits, shots, bit_order, variables, statevector (8 qubits or fewer), method (and engine for a live run), depth, gates, output and errors. A source with no numbered line is QBASIC source (basic=None decides so; True or False forces it). Settings are Session's (qubits, shots, seed, method, precision, noise, inputs, agent). |
| Session | `Session(*, qubits=None, shots=None, seed=None, method=None, precision=None, noise=None, inputs=(), agent=True)` | One QUBASIC terminal driven from Python (see the module docstring). |
| Session.execute | `execute(source, *, basic=False)` | Process the lines of `source` as typed at the prompt (numbered lines enter the program, the rest run as commands) and return what they printed. basic=True numbers QBASIC source first, as LOAD numbers a .bas file. |
| Session.run | `run()` | RUN the program; the result dict (see run()). |
| Session.result | `result(output='')` | The terminal's result() for the last run, with `output` (the text given) and `errors` (its ?... lines) added. |
| Session.counts | `property` | The last run's histogram, or None before a run that measures. |
| Session.variables | `property` | The program's variables as the last run left them. |
| Session.state | `property` | The last run's statevector (computed on first read when deferred). |
